文明の種 Ver.0.6.0 — GitHub Pages / PWA統合向け

主な変更
- 農耕・都市・工業時代の人口上限を大幅増加。食料が十分な場合、毎秒、人口に比例して人口が増加します。
- 人口に応じた生産増幅と、都市・工業時代の食料需要の大幅増加（工業時代は人口規模に対して非線形）。
- 都市・工業時代の施設費用上昇率を引き上げ、無転生での無制限な拡張を難しくしました。
- 工業時代で転生解放。転生すると石器時代に戻り、獲得したポイントを恒久強化（生産力・人口成長・クリック採集）に割り振れます。
- 記録画面の年代記は最新3件を常時表示、残りは折りたたみ。
- 自動人材配置を大量人口でも処理可能な一括配分アルゴリズムに変更。
- ZIPファイルのみバージョン名を先頭に記載し、内部ファイル名は固定。

注意
- 既存セーブ形式 schema=1 を維持。転生データは新フィールドに追加。
- 更新前にJSONエクスポートでバックアップしてください。
- GitHub Pagesで同名ファイルを上書きしてください。HTMLのJS/CSS参照はクエリ?v=0.6.0でキャッシュ更新します。
- PWA統合時は、ゲームフォルダを独立させ、親PWAのService Workerのキャッシュ・スコープ・オフライン動作を検証してください。
- 大量人口での長時間の放置やSafariホーム画面版の実機動作は未検証です。

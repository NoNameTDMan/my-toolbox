# 文明の種 v0.6.1 — My Toolbox統合版

- My Toolbox v1.1.4の安全なセーブ読込・予備セーブ・IndexedDBタイムアウト処理を保持。
- 住民の自動配置は生産速度、保有量、次の建設・研究に必要な資源量を参照して不足資源へ優先配分。
- 施設自動購入は1秒ごとに購入可能な個別ON施設を評価し、資源不足の改善・生産増加・人口上限を考慮。
- 採石場は採石者の上限を増やす施設のため、採石場購入後に自動配置がONなら採石者も再配分。
- ホームへ戻るボタン・セーブ保護・復旧UIを維持。
- My Toolboxのゲームフォルダへ配置すること。独立版の更新は停止。
